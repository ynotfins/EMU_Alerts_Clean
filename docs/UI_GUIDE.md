# UI Guide

## Design Tokens

`ui/theme.ts` exports:

- **Colors**: brand, semantic, text, borders, cards, favorite
- **Radii**: card, chip, button, badge
- **Shadow**: standard card shadow
- **Spacing scale**

## Screens (Key UX)

**Login**: branded, modern auth with demo and show/hide password

**Incidents List**: search, priority chips, distance, favorites, connection banner

**Incident Detail**: map + marker, RESPOND button, priority badge, timeline, employee edit panel (ETA/report)

**Incident Chat**: per-incident, role-labeled messages

**Cases List & Detail**: status chips, notes, tasks, docs, e-sign panel + history

**Supervisor Map**: responders presence markers

**Profile**: role badge, Cash App/Venmo setup, push token dev tools

**Documents Tab**: PDF library with e-sign links

## Interaction

Pull-to-refresh, live filtering, consistent elevation & spacing

Press feedback (scale/opacity), accessible color contrast
