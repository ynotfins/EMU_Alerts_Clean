# Roadmap

## Near-Term

- Background location (TaskManager) with battery-safe cadence
- Supervisor analytics: response times, SLA, heatmaps
- Role-targeted push campaigns (priority-based)
- E-sign provider abstraction (DocuSign adapter)

## Mid-Term

- Offline action queue (compose while offline)
- Media moderation & size quotas
- Customer portal (read-only incident/case + e-sign)

## Long-Term

- Multi-agency federation / mutual aid
- AI assist: triage suggestions, routing, duplicate detection
- Audit/compliance export (PDF bundles, CSV)
