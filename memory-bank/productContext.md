# Product Context: EMU Alerts Mobile App

## Why This Project Exists
The EMU Alerts mobile app provides a modern, real-time emergency alert system for Eastern Michigan University campus safety. It addresses the critical need for immediate, reliable emergency communication in mobile-first environment.

## Problems It Solves
### Emergency Communication Challenges
- Need for instant emergency notifications to campus community
- Real-time incident status updates and tracking
- Mobile-accessible emergency information
- Centralized incident management and timeline

### Solutions Implemented
- **Real-time Updates**: Firebase-powered live incident feed
- **Push Notifications**: Instant emergency alerts to mobile devices
- **Incident Tracking**: Detailed incident views with timeline
- **User Management**: Firebase authentication for secure access
- **Cross-platform**: iOS and Android compatibility

## How It Works
### User Experience Flow
1. **Authentication**: Users sign in with email/password via Firebase Auth
2. **Incident Feed**: Real-time list of campus incidents with filtering
3. **Incident Details**: Tap incident for full details, timeline, and updates
4. **Push Notifications**: Automatic alerts for new incidents
5. **Tab Navigation**: Access to Incidents, Favorites, Chat, Profile

### Key Features Implemented
✅ **Real-time Incident Feed**: Live updates from Firestore
✅ **Incident Management**: Detailed views with severity/status badges
✅ **Push Notifications**: Expo notifications with emergency channels
✅ **Timeline Tracking**: Incident updates with timestamps
✅ **Filtering System**: All, Active, Critical incident views
✅ **Authentication**: Secure Firebase Auth integration
✅ **Testing Tools**: Built-in test functions for development
✅ **Modern UI**: Emergency-appropriate red theme with accessibility

## User Types
### Primary Users
- **Students**: Receive emergency alerts and track incidents
- **Faculty/Staff**: Access emergency information and updates
- **Emergency Personnel**: (Future) Manage incidents and send alerts

### User Experience Achieved
